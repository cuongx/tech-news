TECHNEWS — BỘ BÀN GIAO CHẠY TRÊN MÁY KHÁC (26/11/2026)
Đề tài: Xây dựng website tin tức công nghệ kết hợp thương mại điện tử.

1. BỘ NÀY CÓ GÌ?
- Source TechNews, ảnh bài viết minh họa và 6 sản phẩm thật được lưu trong wwwroot.
- database/TechNews.Full.sql: toàn bộ schema và dữ liệu demo, không cần chạy các Upgrade/Seed rời.
- database/TechNewsDemo.bak: bản sao lưu SQL Server 2022, được lưu cùng source trên GitHub.
- database/Install-Database.ps1: tạo database mới, tự dừng nếu tên database đã tồn tại.
- Run-TechNews.ps1: chọn SQL Server/database và khởi chạy ứng dụng.
- Báo cáo Word/PDF: docs/bao-cao-hoan-chinh.
Database demo gồm 14 bảng, 17 bài viết, 6 sản phẩm, tài khoản admin và customer; đủ schema đặt hàng, lịch sử, sửa địa chỉ, biên tập và thư viện. Đơn hàng ban đầu trống để người nhận tự đặt thử.
Đây là bộ dữ liệu demo độc lập, không chứa tài khoản cá nhân, mật khẩu hoặc địa chỉ đơn hàng của BLOGDB trên máy tác giả.

2. CHUẨN BỊ
- Windows, .NET 8 SDK (bao gồm runtime .NET/ASP.NET Core 8).
- SQL Server 2022 và SQL Server Management Studio (SSMS).
- sqlcmd để dùng trình cài tự động; nếu chưa có, dùng SSMS theo mục 4.
- Internet ở lần chạy đầu để dotnet tải NuGet; không cần Visual Studio nếu chạy bằng PowerShell.
Clone repository hoặc giải nén TOÀN BỘ ZIP vào một thư mục, không chỉ lấy file .sln hoặc .csproj.
Mở PowerShell tại thư mục có TechNews.sln và Run-TechNews.ps1.

3. CÁCH CÀI KHUYẾN NGHỊ (CHỈ HAI LỆNH)
Ví dụ máy dùng SQL Server mặc định localhost:

powershell -NoProfile -ExecutionPolicy Bypass -File .\database\Install-Database.ps1 -Server "localhost" -Database "TechNewsDemo"
powershell -NoProfile -ExecutionPolicy Bypass -File .\Run-TechNews.ps1 -Server "localhost" -Database "TechNewsDemo" -Port 5199

Mở http://localhost:5199
Giữ cửa sổ chạy ứng dụng mở; Ctrl+C để dừng.
Nếu máy dùng SQLEXPRESS, thay Server ở CẢ HAI lệnh thành ".\SQLEXPRESS".
Nếu cổng 5199 đang được dùng, đổi -Port 5200 và mở http://localhost:5200.
Script dùng Windows Authentication. Tài khoản Windows phải có quyền tạo database và kết nối SQL Server. Database mặc định của bộ bàn giao là TechNewsDemo; script chạy tự cấu hình connection string bằng biến môi trường, không cần sửa appsettings.json.
Tên database đã tồn tại: không chạy lại vào database có dữ liệu; dùng tên mới, ví dụ TechNewsDemo2, trong CẢ HAI lệnh. Không tự xóa database cũ.

4. NẾU CHƯA CÓ SQLCMD: DÙNG SSMS
- Kết nối SQL Server bằng Windows Authentication.
- File > Open > File, mở database/TechNews.Full.sql.
- Query > SQLCMD Mode (bắt buộc vì file có :ON ERROR EXIT).
- Execute (F5); file tạo database TechNewsDemo, toàn bộ bảng và dữ liệu demo.
- Chạy lệnh Run-TechNews.ps1 ở mục 3 với đúng Server vừa kết nối.
Không chạy Database.sql cũ hoặc các Upgrade/Seed khác sau khi đã cài TechNews.Full.sql.

5. TÙY CHỌN KHÔI PHỤC FILE .BAK
Chỉ chọn MỘT cách: cài file SQL hoặc restore .bak, không cần làm cả hai.
File .bak được tạo bằng SQL Server 2022, dùng SQL Server 2022 hoặc mới hơn để restore.
- Chép database/TechNewsDemo.bak vào thư mục Backup của SQL Server trên máy nhận (để dịch vụ SQL có quyền đọc).
- Trong SSMS: Databases > Restore Database > Device > chọn file .bak.
- Đặt Destination Database = TechNewsDemo (hoặc một tên mới chưa tồn tại).
- Ở Files, chọn Relocate all files to folder và chọn thư mục Data/Log hợp lệ trên máy nhận. Không giữ đường dẫn dữ liệu từ máy tác giả. Tên logical file trong backup có tiền tố TechNews_Verification_Handoff; đây chỉ là tên file logic, không phải tên database bắt buộc.
- Không chọn ghi đè database có sẵn. Nhấn OK để restore.
- Chạy Run-TechNews.ps1 với đúng tên database vừa restore.
Nếu không restore được do phiên bản SQL, dùng file SQL đầy đủ ở mục 4. Bộ này đã được kiểm chứng trên SQL Server 2022.

6. TÀI KHOẢN DEMO
Quản trị: tên đăng nhập admin / mật khẩu 12345
Khách hàng: tên đăng nhập customer / mật khẩu 12345
Đăng nhập tại /Admin/Login. Đây là tài khoản mẫu công khai cho demo; đổi mật khẩu khi dùng ngoài môi trường học tập.
Người nhận cũng có thể đăng ký tài khoản mới tại /Account/Register.

7. KIỂM TRA SAU CÀI
- Trang chủ có bài viết; /Shop có 6 sản phẩm và ảnh thật.
- admin đăng nhập, mở quản lý bài viết, sản phẩm, đơn hàng.
- customer thêm sản phẩm vào giỏ, chọn tỉnh/phường, đặt COD, xem lịch sử và sửa địa chỉ khi đơn chờ xác nhận.
- Ảnh phải đi cùng thư mục source; SQL/.bak không chứa file ảnh. Không bỏ thư mục TechNews/wwwroot hoặc TechNews/Data.
- Chức năng thanh toán online, giao hàng qua hãng vận chuyển và email chưa tích hợp.
- Giá và tồn kho là dữ liệu demo, không phải báo giá của nhà sản xuất.

8. KIỂM CHỨNG BỘ BÀN GIAO
Đã tạo database hoàn toàn mới từ file SQL; đối chiếu cấu trúc với BLOGDB không thiếu bảng/cột; kiểm tra đăng nhập cả hai tài khoản, đọc tin, ảnh sản phẩm, đặt hàng và quản lý đơn.
File .bak đã qua RESTORE VERIFYONLY WITH CHECKSUM và restore thử sang database khác. Kết quả chi tiết: database/verification.json.
Build còn hai cảnh báo NU1701 từ PagedList/PagedList.Mvc; không có lỗi build trong lần kiểm chứng.
